## 「量价验证 · 信号明细」时间滞后问题 (index.html)

## 「蓄势 vs 爆发」研究 (23:5x)

**用户观点:** 看 90 日 K 线 + 量能图, 觉得"量能爆发后次日买大概率跌" —— 像气球, 爆发那下就是爆掉的时候; 问能不能提前看出在积蓄能量。

**做法:** 新增 `coil_study.py`(可重跑) 用 `data/klines_<日期>.json`(310 只 × 120 日, 21550 券日)做分层统计,
口径与看板「量价验证」一致(信号日收盘确认 → 次日开盘买入 → 持有 h 日收盘卖出)。产出报告 `蓄势研究_2026-09-17.md`。

**结论(证据在报告里):**
1. "爆发后跌"只在**高位**成立: 低位爆发(pos60≤.35) T+20 **+0.95%/胜率49%**; 高位爆发(pos60≥.65) T+20 **−3.18%/27%**,
   平均最大浮亏 −5.5%。爆发次日开盘追, 量比越大次日下跌比例越高(1~1.5x: 53.4% → 3~5x: 58.1%), 但幅度小(中位 −0.08~−0.38%)。
2. **蓄势可量化**(位置低 + 量能萎缩 + 振幅压缩 + 波动压缩 + 量能不升 + 缩量够久 → 蓄势分 0~100), 但**不预测爆发**:
   严蓄势后 5 日内出现放量爆发概率 **0.9%**(全样本 11%); 53% 的单日涨≥5% 前 5 日完全没放过量。
   蓄势分高 → 回撤小(高分档平均最大浮亏 −1.48% vs 低分档 −3.62%), 收益仍≈0 → **防守指标, 不是买入信号**。
3. **可操作的是「点火」不是「猜爆」**: 低位 + 振幅20≤12% + 温和放量 1.5~3× + 收涨 + 前期量能不升
   → T+20 **+0.70%/胜率51%**, T+10 +0.25%/54%, 平均最大浮亏 **−1.81%**(基准 −3.13%), 全样本仅 233 个(1.1%)。
   反向的「高位+放量+涨≥3%」= T+20 −2.76%/35%, 平均最大浮亏 −6.70%。
4. 与看板已有验证一致: 扫描验证里「缩量+低位(放量日)」T+20 +1.02%/49.7% —— 同一个现象。

**待用户决定:** 要不要把这套做成看板页签(「蓄势榜」: 蓄势分 Top / 点火 / 追高区 三张表 + 分档回测), 还是在
放量榜/弹窗里加列。做了就要: 扫描脚本产出 `data/coil_scan_<日期>.json` + `/api/coil` 路由 + 前端页签。
