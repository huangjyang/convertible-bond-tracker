# 2026-09-18

## 需求: "用户觉得网站不错, 想要个小程序版本" —— 可行性调研

**问题三方:** ① 该怎么做 ② 小程序布局是不是全要改 ③ 怎么让小程序能被搜到。
**结论: 技术不难, 卡在"主体 + 类目"上。以个人身份公开上线一个能被搜到的可转债行情小程序, 走不通。**

### 一、合规硬门槛 (官方依据)

| 门槛 | 事实 | 来源 |
| --- | --- | --- |

### 二、"能不能被搜到"

- 搜一搜按**名称**匹配: 名称全局唯一 (错误码 53013), 有保护期 (53019/53020); 无认证 = 无名称保护。
- 搜一搜按**页面内容**收录: 入口「推广与搜索-微信搜一搜-运营中心-内容接入」限 **非个人主体 + 6 个一级类目 + 月均 DAU≥5000 + 上架>30 天 + 已备案**, 且**不支持股票信息服务类目** → 对本站内容类型直接关闭。([内容接入](https://developers.weixin.qq.com/miniprogram/introduction/widget/we-search/WXAPAGES.html))
- sitemap.json + 后台"允许微信索引"是技术手段 (mpcrawler 爬虫), 但受上面类目限制; **web-view 内内容一律不收录**。([SEO指南](https://developers.weixin.qq.com/miniprogram/dev/framework/search/seo.html))
- 后台"搜索关键词"设置: 官方无文档, "最多10个"仅社区经验, **不可作为方案依据**。

### 三、可落地路线 (按现实性排序)

1. **移动端 H5 适配 + 公网部署** (推荐): 后端 `app.py` 12 个 JSON 接口全复用; 前端把 8 tab/16 表做手机布局。绕开微信审核, 但仍需备案域名, 且**个人网站备案同样对"金融/证券"字样敏感**。
2. **个人主体小程序 + 体验版, 不发布**: 个人主体项目成员/体验成员各 15 人 ([接入指南](https://developers.weixin.qq.com/miniprogram/introduction/)); 不发布就不触发备案与类目审核 —— 这是"给朋友的小程序版本"唯一现实形态, 但**体验版搜不到、非成员打不开分享卡片**。
3. **正式发布**: 需 企业主体 + 增值电信业务经营许可证 + 沪深交易所行情授权 → 基本只有持牌/授权信息商做得到。
4. 借道已有平台 (集思录/雪球) 或公众号 —— 证券类内容同样受平台与法规约束。

### 四、如果真要做小程序前端, 改动清单 (布局不是"全改", 但前端要重写)

后端可原样复用, 前置条件: 公网 **HTTPS + 已备案域名**, 并在小程序后台配 **request 合法域名** (本机 :8734 不行)。

| 现在 (`index.html` 2099 行) | 小程序里 |
| --- | --- |
| 顶部 8 个横向 tab | tabBar 最多 5 个 + 其余做二级页面 |
| 16 个 `<table>` | 手机上没有 table, 改卡片行 / 横滑 scroll-view 表格 (**信息密度要重新设计, 这才是"布局全变"的来源**) |
| 4 处 ECharts (+ 行内 sparkline) | `echarts-for-weixin` 的 `ec-canvas`, 或换 uCharts/F2; 小屏要减配 |
| `alert/confirm` | `wx.showModal` |
| `prompt` | 无原生对应, 需自研弹窗 |
| `navigator.clipboard` | `wx.setClipboardData` |
| `localStorage` (模拟仓) | `wx.setStorageSync` |
| `window.open(新闻链接)` | **打不开外部网页**, 只能复制链接 (web-view 个人不可用) |
| 键盘 ←/→ 翻券 | 手势 / 按钮 |
| px 布局 | rpx + scroll-view; WXSS 无 `*` 通配与 body/html 选择器; flex 基本可用 |
| 无 | 新增 `onShareAppMessage` 分享卡片、下拉刷新 |

**平移得了的**: 信息架构、指标口径、图表配置、配色与卡片风格。
**必须重做的**: 表格信息密度、图表尺寸、所有 DOM/浏览器 API、导航结构。

## 落地「方案 0」: 手机端适配 + 添加到主屏幕 (已完成)

**用户选择:** 只自己用, 先做不做小程序的方案 0 —— 让现有页面在手机上像 App 一样用。

### 一、最关键的发现: 手机上行高爆到 336px 的根因

`table{width:100%}` + 只有「标签/核心驱动」列是 `white-space:normal`:
窄屏下浏览器为了把表格塞进 344px, 会把**唯一可换行的列压成一字宽**, 标签竖着排,
单行从 42px 涨到 **336px**(放量表 3 行就 4113px 高)。桌面宽度够, 所以只在手机上出现。

**修法:** 手机端 `table{width:max-content;min-width:100%}` —— 按内容取宽, 靠横滑看后面的列,
行高回到 52px。这条比"把表格改成卡片"更省事, 也不丢信息。

### 二、index.html 改动

1. **响应式(<820px)**: 头部标题独占行/控件一行/状态提示整行; 页签改成**横向滑动 + 吸顶**
   (`position:sticky`, 右边缘渐隐提示可滑); 指数卡片 2 列; `.metrics` 2 列;
   `select,input{font-size:16px}`(防 iOS 聚焦自动放大); 图表高度内联样式用 `!important` 压低。
2. **宽表首列吸顶**: `table th/td:first-child{position:sticky;left:0}` +
   第 1 列是"#"的榜表加 `class="pin2"`, 第 2 列(券名)跟着吸顶(`left:36px`)。
   效果: 横滑时券名/日期始终可见(实测 scrollLeft=260 时首列 x 不变)。
3. **弹窗手机整屏**: `.mbox` 无圆角满宽; ✕ 改 `position:fixed` 圆形按钮(`.mhead{padding-right:46px}` 防压字);
   **19 项指标默认只显示前 6 项** + 「展开全部指标 ▾」(`.mmore` + `.metrics.open`),
   投研附加指标(`mcm-keep`)不折叠; 打开弹窗时 `lockBody(true)` 锁背景滚动。
4. **图表手机适配** `polishChartAxes(chart)`: 包一层 `setOption`, 把 xAxis/yAxis 的
   `axisLabel` 改成 `fontSize:9 + hideOverlap:true`, 副轴再 `splitNumber:3`。
   否则时间轴挤成 `10:0010:3011:00`, 成交额轴 `10万/8万/6万` 叠一起。
   `#mMinute` 高度由 JS 给: 手机 260px / 桌面 320px / 无数据 118px。
5. **主屏幕支持**: `viewport-fit=cover` + `theme-color` + `apple-mobile-web-app-*`
   + `apple-touch-icon`/`icon` + `manifest.webmanifest`; `env(safe-area-inset-*)` 兜底写法
   (`padding:8px 10px 48px` 后跟 `calc(...env()...)`)。
6. 头部新增「⟳ 刷新」按钮(`location.reload()`): 加到主屏幕后**没有下拉刷新**, 必须留个入口。
7. 切页签时(仅手机)把当前页签滑到中间 + 回到页面顶部。

### 三、新增文件 / app.py 改动

- `make_icons.py`(纯标准库手写 PNG, 无 Pillow): 生成 `assets/icon-{180,192,512}.png`
  —— 蓝底(#2b5aed) + 3 根递增柱子, **满幅不透明**底(同时满足 iOS 与 Android maskable)。
- `manifest.webmanifest`: standalone / 竖屏 / theme-color / any maskable 图标。
- `app.py`:
  - **监听 `0.0.0.0`** 而不是 `127.0.0.1`(手机要能用局域网 IP 打开), 启动时打印
    `http://127.0.0.1:8734` 和 `http://<局域网IP>:8734`(`_lan_ips()`, UDP connect 探出口网卡)。
  - 新增路由 `/manifest.webmanifest`, `/favicon.ico`; `/assets/` 补齐 png/css/json 的 Content-Type。
- `tests/voltab_smoke.mjs`: 默认端口 `8799 → 8734`(其它三套都是 8734, 之前单独跑必然
  `fetch failed: ECONNREFUSED 127.0.0.1:8799`, 容易被误判成代码坏了)。

### 五、使用与注意事项

- 手机(同一 Wi-Fi)打开 `http://192.168.0.103:8734` → Safari 分享 → 「添加到主屏幕」。
- 服务进程: 旧进程(127.0.0.1)已被杀掉重启为 0.0.0.0; **当前实例是 nohup 起的独立进程,
  Mac 重启后不会自动回来** —— 要长期稳定, 得自己写个 launchd plist 或每次手动
  `cd ~/Documents/可转债跟踪 && python3 app.py`。
- 绑 0.0.0.0 = 同一 Wi-Fi 下任何人都能打开这个看板(还能触发抓数), 在公共 Wi-Fi 上别开。
- 数据抓取仍是"打开页面触发"(`/api/refresh`), 手机上打开页面同样会触发。
